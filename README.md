# iyzico - OpenCart Payment Gateway

> ⚠️ **This branch contains no installable code.**
> The plugin is maintained in a separate branch for each product and OpenCart
> version. Pick the branch or release that matches your store from the tables
> below — do not install from `master`.
>
> ⚠️ **Bu branch'te kurulabilir kod bulunmuyor.**
> Eklenti, her ürün ve OpenCart sürümü için ayrı branch'lerde geliştiriliyor.
> Aşağıdaki tablodan mağazanıza uyan branch'i veya release'i seçin; `master`
> üzerinden kurulum yapmayın.

## Installation

Download the `.ocmod.zip` file from the release that matches your OpenCart
version, then install it from **Extensions → Installer** in the admin panel.

Detailed guide: <https://dev.iyzipay.com/tr/acik-kaynak/opencart>
